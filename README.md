CareerNexus is a hybrid AI-driven career development platform that automates resume evaluation and professional upskilling. It serves as an intelligent bridge between a user's current profile and their target career goals.

🚀 Key Features
ATS Scoring: Evaluates resume quality using a weighted heuristic scoring model.

AI Career Agent: Autonomously identifies technical skill gaps based on seniority.

Strategic Roadmapping: Generates a 3-step action plan for career transitions.

MOOC Recommendation: Matches users with advanced courses from Dataset1.csv.

🛠 Technical Architecture
The project utilizes a Hybrid Intelligence approach for speed and explainability:

Weighted Heuristic Scoring: A deterministic engine assigning "weights" to resume attributes to calculate an ATS compatibility rate.

Symbolic AI (Expert System): Mimics human mentor reasoning for proactive Gap Analysis.

Rule-Based Seniority Mapping: An NLP classifier that categorizes users into "High" or "Middle" tiers using professional tokens.

Content-Based Filtering: Matches user profiles with specific course metadata for high-precision recommendations.

💻 Tech Stack
Language: Python 3.x

Libraries: Pandas, PyPDF2, python-docx

Environment: Google Colab / Jupyter Notebook

Logic: Rule-Based Expert System (Non-probabilistic)
